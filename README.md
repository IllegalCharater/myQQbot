# myQQbot

基于 Electron、Node.js 与 OneBot v11 的本地 QQ AI 机器人实验项目，可接入 OpenAI 兼容接口，并通过桌面控制台管理模型、会话、记忆和消息响应策略。

## 主要功能

- 通过 OneBot v11 正向 WebSocket 接收和发送 QQ 消息
- 支持 OpenAI 兼容的模型 API，可配置多个模型服务
- 支持群聊、私聊、@ 响应、关键词响应和概率响应
- 使用独立无状态会话控制上下文长度与 Token 成本
- 保存本地消息存档、会话记录和群友长期记忆
- 支持图片理解、网页搜索、表情包、引用、@ 和戳一戳
- 统计模型调用量、Token 用量和估算费用
- 提供 Electron 桌面控制台、托盘运行和明暗主题

## 工作方式

1. OneBot 协议端将新消息写入本地存档。
2. 消息命中响应规则后，程序创建一次独立模型会话。
3. 提示词由系统规则、必要的历史摘要和本次新消息组成。
4. 会话结束后不保留模型侧上下文，长期信息单独写入本地记忆。
5. 处理期间收到的新消息会进入下一次会话，避免无限增长上下文。

所有运行数据默认保存在本地 `data/` 目录中，该目录不会被 Git 跟踪。

## 环境要求

- Windows
- Node.js 20 或更高版本
- 一个兼容 OneBot v11 正向 WebSocket 的 QQ 协议端
- 一个 OpenAI 兼容模型 API

SnowLuma 可作为协议端使用，但它是独立第三方项目，不包含在本仓库中，并受其自身 EULA 和使用条款约束。

## 安装与启动

安装依赖：

```bash
npm install
```

启动桌面端：

```bash
npm start
```

也可以双击项目根目录中的 `启动QQ机器人.bat`。

仅启动 Web 服务：

```bash
npm run server
```

随后访问 `http://127.0.0.1:3210`。

## 基本配置

首次启动后，在控制台中依次完成：

1. 填写模型服务的 Base URL 和 API Key。
2. 获取并选择要使用的模型。
3. 配置 OneBot WebSocket 地址。
4. 选择允许机器人工作的群聊或好友白名单。
5. 根据需要调整响应档位、关键词、人设和搜索服务。

请从低频响应开始测试，确认行为符合预期后再逐步开放使用范围。

## 数据与隐私

- API Key、聊天存档、记忆和会话记录可能包含敏感信息。
- 不要提交 `data/`、日志、登录态或第三方协议端配置。
- 将代码分享或推送到公开仓库前，请先执行只读扫描：

```bash
node scripts/sanitize-release.mjs --scan
```

如需清理本地部署数据，请先预览清理范围：

```bash
node scripts/sanitize-release.mjs --dry-run
node scripts/sanitize-release.mjs
```

第二条命令会清理 Key、白名单、存档和登录态，执行前请自行备份需要保留的数据。
