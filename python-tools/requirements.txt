# 本项目全部 Python 工具的依赖。**只有这一份** —— 新增 Python 工具时依赖加在这里，
# 不要在工具旁边另开一份（两份清单必然漂移，最终没人知道该装哪个）。
#
#   python-tools/jmcomic_download.py      → jmcomic（漫画下载）
#   python-tools/pic_image_search_worker.py → PicImageSearch（搜图 worker）
#
# 安装（两个工具共用一个解释器，路径由配置项 `python.path` 指定）：
#
#     <python> -m pip install -r python-tools/requirements.txt
#
# <python> 就是 `python.path` 里填的那个解释器；解析链（`src/core/python-runtime.ts`）是
# 随包内置的运行时（打包时带了 --with-python 才有这一层，它就是
# <安装目录>/resources/app/python-runtime/python.exe）→ python.path → QQ_AGENT_PYTHON →
# conda run（环境在设置页「Python 工具」的 conda 环境那一栏配：环境名走 -n、环境目录走 -p）。
# ⚠️ 有内置运行时时，`python.path` 不生效（内置那份带着装好的依赖，是唯一"确定能用"的）。
# （更早的环境变量别名 JMCOMIC_PYTHON 已于 2026-09-29 废弃，两个工具共用一个解释器。）
